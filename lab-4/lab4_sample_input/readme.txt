These are data files which can be used, at your own risk, as input to Lab 4.
The file names are of the form `typeSize.dat` where Size is the number of entries and type is one of:
	asc  - for ascending ordered file
	dup  - for a randomly ordered file containing a higher percentage of duplicates
	ran  - for a randomly ordered file containing very few, if any, duplicates
	rev  - for a reverse ordered file

'.dat' is a meaningless file extension, the files are in plain text with 1 integer per line and can
be opened with any text editor. 'dat' is simply short for data.
